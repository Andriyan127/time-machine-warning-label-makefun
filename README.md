# time-machine-warning-label-makefun

Entry for the make.fun competition **"Funniest Time Machine Warning Label"** — write one warning label for a time machine, max 120 characters, aiming for the biggest laugh.

## The entry

> CAUTION: Do not step on any butterfly. One already cost us the entire 21st century.

The label turns the classic butterfly effect — one careless step in the past erasing the future — into a deadpan safety notice, with the punch landing in the last few words: the whole 21st century is already gone.

## How it works

`main.py` writes exactly that one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`), with no trailing newline and no extra text.
